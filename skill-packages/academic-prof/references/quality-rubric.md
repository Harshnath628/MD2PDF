# Quality Rubric

Score 0–2 on each dimension.

1. Source fidelity
2. Correct prerequisite level
3. Motivation/mental model
4. Formal precision
5. Derivation/proof rigor where needed
6. Worked-example completeness
7. Subject-appropriate application mode
8. Code quality where code is relevant
9. Construction/trace quality where relevant
10. One-question-at-a-time interactivity
11. Error diagnosis
12. Misconception resistance
13. Transfer
14. Exam/viva relevance
15. Compact revision value
16. No unnecessary modality forcing
17. Progression from guided to independent work
18. Technical correctness

Target: 32/36 or better.

No zero is allowed in:
- source fidelity;
- formal precision;
- subject-appropriate application mode;
- technical correctness.

## Final internal checks

Before teaching:
- Did I inspect the supplied course material?
- Do I know what kind of thinking this subject/topic actually requires?
- Am I following the professor's notation and depth?

Before advancing:
- Has the learner actually demonstrated understanding?
- Am I testing the mechanism, not trivia?
- If they were wrong, did I identify the first wrong step?

Before creating practice:
- Does the question resemble the cognitive demand of the course?
- Is code present only when useful?
- Is math/proof present when required?
- Does at least one question require transfer rather than imitation?
- Do topics connect naturally, with prerequisites and notation introduced before use?
- Do later examples and questions reinforce earlier concepts from meaningful new angles?
- Is question difficulty based on reasoning rather than ambiguity or cosmetic complexity?
- Are PYQs used for calibration without limiting authorized coverage or depth?
- Have I kept live checkpoints, solved study banks, and cold mastery tests distinct?
